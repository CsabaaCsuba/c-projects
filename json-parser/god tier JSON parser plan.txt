JS_Object struct:
    if, the Dtype is NULL, nothing else matters.
    if the Dtype is a NUMBER, the void pointer should be cast to a double pointers
    if the Dtype is Boolean, the void pointer should be cast to an bool pointer
        #define bool unsigned char
        #define false 0
        #define true 1
    if the Dtype is a STRING, the void pointer should be cast to a char array
    if the Dtype is a LIST, the void pointer should be cast to a pointer (array) of JS_Objects
    if the Dtype is JSON, ONLY THEN does the Keys field matter. the void pointer should be casted to a pointer (array) of JS_Objects
